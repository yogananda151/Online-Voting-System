We aim to build a secure and user-friendly online voting system using Python (Flask), MySQL, and a simple UI/UX frontend. The system will provide two types of login: Admin and Voter.

1. Login System

Users can log in either as Admin or as Voter.

Voter Login will include facial recognition authentication to ensure security.

2. Admin Dashboard

After login, the Admin dashboard will contain the following features:

Live Elections

Shows the list of ongoing elections.

Clicking on an election displays:

Number of voters who have voted vs. not voted.

Live results (only visible to Admin).

Admin can cancel an election at any time.

Add Election

Admin can create a new election by entering:

Election name, place name, voter list, start time, end time.

Candidate details (candidate name, party name, candidate image, party image).

Voters List

Admin can upload a voter list via an Excel file.

After uploading, the complete voter list will be displayed.

Finished Elections

Shows completed elections.

Clicking on a completed election displays:

List of voters who voted and who did not.

Final results (Admin can choose to publish results).

Upcoming Elections

Shows elections scheduled for the future.

Admin can edit details (date, candidates, voter list) before the election starts.

Logout

3. Voter Dashboard

After login, the Voter dashboard will have the following features:

Live Elections

Shows the list of ongoing elections.

After selecting an election, the voter can view the candidate list and cast their vote.

Each voter can vote only once per election.

Completed Elections

Displays elections that have ended.

Clicking on a completed election shows the results (only if the Admin has published them).

Logout

4. Key Features & Rules

Each voter can cast only one vote per election.

Secure login with facial recognition for voters.

Admin controls election management (create, cancel, publish results).

User-friendly and intuitive UI.
